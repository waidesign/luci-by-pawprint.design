# Global Brain: Default Files

These are the **defaults** Luci ships. On first use, Luci copies them into **your own Global Brain** at `~/.luci/brain/` (or `$LUCI_HOME/brain/`), and from then on reads and writes only your copy. Updating Luci never overwrites your files, and your decisions never end up in Luci's repository.

- Share one brain across machines: set `LUCI_HOME` to a synced folder (Dropbox, OneDrive, or a private git repo).
- This README is not copied; your Global Brain gets its own.

Edit the files here only to change what **new** users start with.
