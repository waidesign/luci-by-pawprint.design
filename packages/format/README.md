# @luci-dev/format

Luci's file formats: the schemas, parsers and writers for `.luci/` files, design captures and feedback notes.

This package is a part of [Luci](https://github.com/waidesign/luci-by-pawprint.design#readme), design control for AI coding agents. You do not need to install it yourself: start with the CLI, which brings it in.

```bash
npm install -g @luci-dev/cli
luci init
luci serve
```

See [@luci-dev/cli](https://www.npmjs.com/package/@luci-dev/cli) for setup and updating.

MIT licensed. Runs on your machine: no telemetry, no account.
