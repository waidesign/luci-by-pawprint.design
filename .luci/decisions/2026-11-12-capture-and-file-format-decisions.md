# Capture and file format decisions

- Date: 2026-11-12
- Status: accepted
- Area: Capture

## What
Capture and file format decisions

## Why
Source: docs/PRD.md Part 2, Decisions made on 12 Nov 2026.

- Capture delivery: an on-page toolbar, a thin browser extension for any site and a dev toolbar for your own projects.
- Capture basket: yes.
- Images: fully blocked; components and SVG drawings stay selectable.
- File format: our own spec, with export to Google DESIGN.md format.
- Units: a setting, px, rem or both.
- Colour format: a setting, hex, oklch, hsl or rgb; the authored value is always kept alongside.
