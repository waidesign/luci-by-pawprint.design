# Official library: design core plus a coding bridge

- Date: 2026-11-12
- Status: accepted
- Area: Skills

## What
Official library: design core plus a coding bridge

## Why
Design core: UI/UX, design systems, accessibility, motion and micro-interactions, components, shadcn, Tailwind and React UI, 3D, mobile UI, canvas design, prototyping. Coding bridge: tdd, webapp-testing, code-review, react-best-practices, composition-patterns. Left out of the official library: cloud/Azure, video and AI media, documents, agent workflow, general writing, architecture, database. Users can still add any skill to their personal library with luci skills add.
